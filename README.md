# Qt Media Player

Простий та ефективний десктопний мультимедійний плеєр на базі C++ та бібліотеки **Qt 6** (Qt Multimedia).

## Можливості

- **Відтворення аудіо та відео:** підтримка форматів MP4, AVI, MKV, MP3, WAV, OGG тощо.
- **Джерела медіа:**
  - Відкриття локальних файлів через діалогове вікно.
  - Потокове відтворення медіа за прямим URL-посиланням.
- **Керування відтворенням:**
  - Відтворення / Пауза (Play/Pause).
  - Зупинка відтворення (Stop).
  - Швидка перемотка назад на 10 секунд (`-10s`).
  - Швидка перемотка вперед на 10 секунд (`+10s`).
  - Інтерактивний повзунок прогресу з відображенням поточного та загального часу.
- **Керування звуком:** повзунок регулювання гучності від 0% до 100%.

## Системні вимоги

- **Компілятор C++:** підтримка стандарту C++17 (GCC, Clang або MSVC).
- **CMake:** версія 3.16 або новіша.
- **Qt 6:** встановлені компоненти:
  - `Qt6Core`
  - `Qt6Gui`
  - `Qt6Widgets`
  - `Qt6Multimedia`
  - `Qt6MultimediaWidgets`

## Встановлення залежностей (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install build-essential cmake qt6-base-dev qt6-multimedia-dev
```

## Збирання проекту

1. Створіть директорію для збирання та перейдіть у неї:
   ```bash
   mkdir build && cd build
   ```

2. Сконфігуруйте проект за допомогою CMake:
   ```bash
   cmake ..
   ```

3. Скомпілюйте проект:
   ```bash
   cmake --build .
   ```

## Запуск

Після успішного збирання виконайте бінарний файл:

```bash
./Media_Player_Lab2
```

## Структура проекту

- `main.cpp` — точка входу в програму, ініціалізація `QApplication`.
- `MediaPlayer.h` / `MediaPlayer.cpp` — реалізація інтерфейсу користувача та логіки взаємодії з `QMediaPlayer`.
- `CMakeLists.txt` — конфігураційний файл для збирання проекту.
